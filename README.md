# 🏦 Rust ile Banka Uygulaması

![Rust](https://img.shields.io/badge/Language-Rust-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

Bu proje, Rust programlama dili kullanılarak geliştirilmiş basit bir banka uygulamasıdır. Kullanıcılar hesap oluşturabilir, bakiye sorgulayabilir, para yatırabilir ve çekebilirler. Proje, Rust'ın bellek güvenliği ve performans avantajlarını kullanarak güvenli bir finansal işlem ortamı sunmayı hedeflemektedir.

---

## 🚀 Özellikler

- **Hesap Oluşturma:** Yeni kullanıcı hesapları oluşturabilirsiniz.
- **Bakiye Sorgulama:** Mevcut hesap bakiyesini görüntüleyebilirsiniz.
- **Para Yatırma:** Hesabınıza para yatırabilirsiniz.
- **Para Çekme:** Hesabınızdan para çekebilirsiniz.
- **Hesap Silme:** Mevcut hesabınızı silebilirsiniz.

---

## 🛠️ Kullanılan Teknolojiler

- **Programlama Dili:** Rust
- **Paket Yöneticisi:** Cargo
- **Veri Yapıları:** Struct, Enum
- **Hata Yönetimi:** Result, Option
- **Dosya Yapısı:**
  - `src/main.rs`: Ana uygulama dosyası
  - `Cargo.toml`: Bağımlılık ve proje yapılandırma dosyası
